# PhishTriage allowlist: domains whose IOCs are NOT sent for lookups in week 3.
#
# Allowlisted means "do not spend API quota on this", NEVER "this is safe".
# Allowlisted IOCs are still shown in the report, marked "skip".
#
# One domain per line. A domain also covers its subdomains:
#     google.com        covers www.google.com and mail.google.com
# A line starting with "!" is an exception, for subdomains where anyone can host
# content (and so can host a phishing page). The most specific line wins:
#     !docs.google.com  means docs.google.com is always looked up
# Never add hosting platforms where anyone can publish (cloudfront.net, amazonaws.com,
# web.app, github.io, sharepoint.com, blob.core.windows.net, ...).
#
# Run with your own file:  phishtriage analyze email.eml --allowlist my-allowlist.txt
